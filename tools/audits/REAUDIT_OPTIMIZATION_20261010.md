# Optimization reaudit — 10 October 2026

Five current correctness gaps reproduced and fixed in their existing owners. No new worker, URL service, queue, parser package, runtime bundle or performance default. This review uses the maintained `noobrocket/` source. Historical [full review](../FULL_SYSTEM_REVIEW.md), [plan](../IMPROVEMENT_PLAN.md) and [batch record](../batches/BATCH_FIXES.md) supplied leads, not proof of the current revision.

The review covered local CSS admission/publication/retries, the Chromium worker and stylesheet generator, JS/CSS minification, JS defer/delay, font preparation, modern image generation/delivery, image dimensions, asset-rule application, shared performance hints and browser link preparation. No fixture bootstrapped or changed the protected `.artifacts/wordpress` installation. The link PHP fixture imported native WordPress classes without booting that site or writing its state. All other proof used native owners with mocks, owned temporary files or intercepted browser resources.

## Confirmed findings and fixes

| ID | Consequence before this fix | Responsible owner and current behavior |
| --- | --- | --- |
| QOPT-01 — P1, native reproduction and Chromium proof | Delay JS matched only quoted `src` and `type`. Valid `src=/app.js` became inert without a recovery URL; `type=module` lost module execution; unquoted JSON-LD became an executable delayed script. Attribute-like text inside another attribute could also interfere. | [`DelayJS/HTML.php`](../../noobrocket/inc/Engine/Optimization/DelayJS/HTML.php:204) extends the existing tag/attribute matchers. Exact attribute names, quoted and unquoted assignments, entities and quoted `>` are handled without changing assignment bytes. Non-JavaScript types stay untouched. The existing CSP/runtime readiness gates stay intact. |
| QOPT-02 — P1, native reproduction | The historical host fix reached `UrlTrait`, while the actual minifier base still matched host text anywhere in a URL. `site.test.other` and `remote.test/site.test/...` were classified local. CSS imports and dimensions retained similar substring checks. Wrong bytes or dimensions could be taken from a local same-path resource. | [`AbstractOptimization.php`](../../noobrocket/inc/Engine/Optimization/AbstractOptimization.php:137) compares parsed hosts exactly, case-insensitively and with trailing-dot normalization. [`CSSTrait.php`](../../noobrocket/inc/Engine/Optimization/CSSTrait.php:441) uses that owner for minifier consumers and exact parsed hosts for its other consumers. [`ImageDimensions.php`](../../noobrocket/inc/Engine/Media/ImageDimensions/ImageDimensions.php:213) uses exact parsed hosts. Local, root-relative, protocol-relative and explicit CDN behavior remains covered. |
| QOPT-03 — P1, native reproduction and Chromium proof | JS exclusions depended on literal dynamic templates such as `type="module"`. Single-quoted/unquoted module types were admitted. Combining admitted remote modules before its exclusion guard; the inline branch also missed intrinsic protection. Empty dynamic templates skipped configured path exclusions entirely. Moving a module changes relative imports; combining it also changes its execution type. | [`AbstractJSOptimization.php`](../../noobrocket/inc/Engine/Optimization/Minify/JS/AbstractJSOptimization.php:103) intrinsically preserves modules and native opt-outs, including encoded values and bare opt-out attributes. Configured exclusions always run. [`Combine.php`](../../noobrocket/inc/Engine/Optimization/Minify/JS/Combine.php:154) applies that guard before its local/remote split and inline admission. Native dynamic templates remain supported. |
| QOPT-04 — P1, failing native regression before fix; Chromium recovery proof | When one selected source returned no usable bytes, another source could still produce a bundle. Combining then removed both originals, silently dropping the unavailable script. This includes a 503, transport error and empty local/remote source. | [`Combine.php`](../../noobrocket/inc/Engine/Optimization/Minify/JS/Combine.php:301) abandons the partial bundle when any selected local/remote source is unavailable. Every original tag remains. It reuses the existing local-cache outcome; no resource API or new retry system. |
| QOPT-05 — P1, native output and Chromium reproduction | Nonced external and inline scripts ran under a nonce-only CSP before combining, then failed because the emitted bundle lost their nonce. Successful JS minification removed original SRI metadata. The Delay CSP gate did not cover these earlier transformations. | [`AbstractJSOptimization.php`](../../noobrocket/inc/Engine/Optimization/Minify/JS/AbstractJSOptimization.php:111) intrinsically preserves scripts carrying `nonce` or `integrity`, independent of dynamic lists, quoting and attribute-name case. Both minification and combining retain their original URL/attributes or inline bytes. Ordinary inline scripts still combine, and same-origin scripts still optimize and execute under enforcing `script-src 'self'`; no blanket CSP bypass, nonce propagation or SRI recomputation. |

The JS combination branch remains reachable in [`JS/Subscriber.php`](../../noobrocket/inc/Engine/Optimization/Minify/JS/Subscriber.php:52) when saved `minify_js` and `minify_concatenate_js` are both enabled. Its native option pre-filter can disable combination when Delay JS applies. A hidden or discouraged UI option does not remove this saved/programmatic branch.

## Retained design and measurement limits

- Local CSS keeps original styles until a current complete result exists. Failed, unsupported, obsolete or missing publications preserve fallback. Attempts and serial viewport work remain bounded. Same-URL manual source edits still require explicit regeneration or versioned URLs; no visitor-time freshness requests were added.
- Fonts retain the current three-second download-admission budget, two-second individual request limit, complete publication and five-minute failure cooldown. Cold preparation remains synchronous. No installed-host measurement established the need for a separate font worker.
- Modern images keep the five-percent byte-benefit threshold, complete responsive families, per-render derivative memoization, four-encode/soft-deadline generation, ownership checks and original fallback. Real GD/Imagick quality/capacity needs representative image checks on the target host.
- Asset rules keep the empty-rule fast path, native dependency protection, private preview scope and late-enqueue ownership. Browser preparation keeps native exclusions, Save-Data/slow-network checks and normal navigation.
- Local CSS CPU/RSS, minimum supported platforms, persistent-object-cache contention, representative themes/builders/commerce, complete site-policy compatibility and production FCP/LCP/CLS/p95 remain separate compatibility/performance evidence. The browser checks prove the stated nonce/SRI/self-source policies, not every installed-site policy or third-party runtime. No production performance claim follows from this report.

No packaging, commit, push or deployment. No gettext keys changed and no served JS/CSS bundle required regeneration.
